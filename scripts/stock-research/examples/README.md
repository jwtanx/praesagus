# Fictional template

Run `python scripts/stock-research/demo.py` from the repository root. The Python fixture is authored in `demo.py`; it does not download prices, fit a model or load credentials. Outputs go into a new private timestamped generation, never this folder.

The authored reference is 2026-10-14. Calendar windows are the following 1, 3 and 5 exchange sessions and the next exchange week. Four main fictional instruments and one separate speculative name illustrate unknown native counts, negative financial metrics, a zero cost versus missing cost, inverse-fund direction, literal formula-looking names and unvalidated numerical forecasts. These examples establish no real instrument recommendation or predictive performance.
