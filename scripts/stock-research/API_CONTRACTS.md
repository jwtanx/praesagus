# Standalone stock-research REST contracts — PRSG-110

This is a bounded, injectable provider wrapper with offline fictional regressions. No authenticated live pilot has been run for this ticket. It does not yet implement universe selection, persistent ingestion, training, forecasts, scheduled collection or exports; those are separate program tickets. Unknown provider capabilities remain unknown.

## Implemented boundary

`ResearchProvider` requires injected API key, signer, transport, millisecond clock and nonce capabilities. Importing these modules performs no credential, Keychain or network access. `build_live_provider` calls the existing secure credential loader only when a caller explicitly selects an authorized live operation; its `allow_live` flag is a software input, not a permission system. The offline tests use fictional injected capabilities exclusively.

`ResearchReadTransport` inherits the existing TLS verification, fixed `webapi.moomoo.com:443` host, TLS 1.2 minimum, redirect rejection, identity-encoding and response-size checks, connection cleanup and request deadline behavior. Its separate allowlist permits only:

| Method | Endpoint | Wire/data boundary |
|---|---|---|
| POST | `/api/v1.0/quote/stock-screen` | US filter, explicit retrieve descriptors and sort, limit at most 300, opaque body `next_key`, `data.items`, top-level `pagination` |
| POST | `/api/v1.0/quote/stock-basicinfo` | 1–400 unique US codes, `data.basic_list`, missing/unrequested/duplicate identities checked |
| POST | `/api/v1.0/quote/snapshot` | 1–400 unique US codes, `data.snapshot_list`, observed prices/source time kept separate from completed bars |
| GET | `/api/v1.0/quote/US.<symbol>/history-kline` | Explicit inclusive ISO start/end, daily `ktype=2`, `autype=0..2`, at most 370 bars per request |

Account/order/news routes, arbitrary URLs, foreign market paths and arbitrary query keys are excluded. The old `SecureReadTransport` and reporting collector were not edited or widened. Signing preserves the sent body/query bytes: timestamp, uppercase method, path, raw query and SHA256 body digest joined by newlines, using the existing injected signer contract.

Requests are sequential within the provider; concurrent reads are rejected. Frozen local request, page, row and per-request timeout budgets bound work. The default request budget is 128; an explicit validated override may raise it to at most 2048. Full-universe multi-year bootstrap may therefore require incremental bounded runs and must report shortfalls rather than silently enlarge the default. A separately approved pilot can use a much smaller budget such as five requests. These numbers are **local safety limits, not verified REST quotas**. HTTP 429 stops the instance with a sanitized error and a bounded Retry-After hint; there is no automatic retry or sleep. Upstream bodies, credential/signature values and dependency exception messages are never copied into error text/context. Batch/request/provider reprs hide contents. Injected synchronous capabilities must honor their timeout; the wrapper cannot interrupt an uncooperative callable. The inherited transport's OS DNS/header trickle limitation remains; these checks do not certify an overall worker deadline or distributed quota coordination.

## Screening units, missingness and paging

The documented `simple_property_result` fixture is decoded only after matching the exact ordered query descriptor and typed `res`: result_type 1/dval, 2/ival (integer or documented decimal string), or 3/sval. Booleans, malformed numbers, missing typed values and mismatched descriptors are not coerced. Formatted `value` is never a numeric fallback. Documented simple-factor scaling is price 2201 /1000 and market cap 2301 /1000. Cumulative factors 3104/3105 and daily 3102 use their documented cumulative family; requesting them (or 3102) as simple fields is rejected. The reviewed turnover /1000 and volume raw units cannot be applied to an unestablished cumulative response wrapper. Unknown simple-factor units remain explicitly unavailable, including typed strings whose semantic factor is not established. REST tags are distinct from SDK/OpenD value_type.

The reviewed cumulative requests are `cumulative_property:{name:3104|3105,days:20,period_average:true}` and daily change rate `cumulative_property:{name:3102,days:1,period_average:false}` (including its discovery sort); retrieve and sort preserve that exact descriptor. Its exact cumulative response-wrapper spelling/property echo is **not established by the cited response example**. The current decoder returns `cumulative-response-shape-unverified`, with no inferred raw/numeric result. The authored unknown-wrapper fixture tests rejection of inference, not live compatibility. Resolving the shape requires Lead-reviewed live evidence and a scoped decoder follow-up. Period average is not a median; required 20-session median turnover must be calculated later from actual complete bars. Daily 3102 may sort provider discovery candidates, but its decoded rate stays unavailable: response shape and base units are unresolved, and raw values are never normalized into an inferred ratio. Other 3102 windows/period averages are rejected. Verified winner/loser final ranking requires completed-bar returns.

Only the reviewed US market filter is accepted initially; unsupported screening filters/descriptors fail explicitly. Query bytes remain frozen apart from opaque body next_key. Duplicate codes, repeated cursor, empty has_more page, oversized page, inconsistent total and terminal-cursor contradictions stop the operation. Reaching a page cap returns truncated status; terminal output shorter than reported total returns partial status, never a silently full universe.

## Canonical observations and history

Basic identity retains a validated stock_id exactly as returned (positive integer or decimal ID string); this internal provider security ID does not establish issuer or share-class grouping. Basic identity does not imply issuer strategy, signed leverage, sector or a fundamental data period. `stock_type=ETF` can include other funds/trusts/REITs; absent sector and fundamental-period provenance remain null. No additional profile/sector endpoint is authorized here.

Snapshots retain source update milliseconds, actual data_date, retrieval/known time, raw numeric price/volume/turnover and validity flags. Missing fields stay null. Today low/high, when returned, remain live observations with their actual session date; they are not reclassified as completed model bars. Quote movement, screener match totals and local indicators never fill native UI bullish/bearish count columns.

History requires finite positive open/high/low/close with low <= open/close <= high, nonnegative integer raw volume and finite nonnegative turnover. Missing volume_precision is unverified units; volume is divided by 10**volume_precision. Prices/turnover use their documented ordinary units. Invalid/missing OHLC rejects the page. Duplicate dates/timestamps, invalid or future milliseconds and inconsistent raw offset/date arithmetic reject history. Raw date, time_key and integer time_zone are retained. Offset arithmetic uses the documented minutes contract with explicit time_zone_unit_status=documented-minutes/runtime-unverified and the documentation source URL; runtime units and provider bar finality remain unverified. Actual calendar/retrieval evidence does not establish those provider capabilities. A documented daylight example is not used to guess a timezone ID, and raw -4 is never silently converted to -240.

Each row carries adjustment mode, source, retrieval/first-known time and response-hash revision vintage. Currency stays null unless the caller supplies attributable `CurrencyEvidence` for that exact security, known by retrieval. The class validates its shape/cutoff, not the contents of the external source. `US.` alone never proves USD. Session completion requires a caller-supplied actual exchange-session close map; absent calendar evidence yields calendar-unverified. Coverage at least 252 requires the full required completed-session set, usable USD bars and known-time cutoff coverage; a raw row count cannot establish it. This wrapper supplies no exchange calendar or point-in-time membership/delisting evidence.

Three-year bootstrap can be requested with explicit start/end and bounded calendar-date windows (at most 180 days each), never an unbounded cursor walk. The next end is the oldest actual returned session date minus one day; an empty window advances to the requested left boundary minus one day. Strict backward progress and global date/timestamp uniqueness are required. A short/full page can be followed safely using actual dates, while missing sessions are rejected by calendar coverage checks rather than guessed. `next_time` is retained as raw milliseconds with unverified-not-used status; its relationship to the date-only end parameter is unresolved and it is never translated into a request end date. Repeated raw cursors cannot drive the loop. Page/request/row budget exhaustion remains visible, and missing sessions remain a coverage gap even after all bounded windows are visited. Current adjusted backfills and revision vintages do not prove historical point-in-time availability.

## Issuer registry and capability receipt

`etf_metadata.csv` contains 41 issuer-attributed identity observations reviewed on 2026-10-14. It is a **classification lookup only** for independently market-discovered names. It cannot seed candidates, fill quotas, establish a US listing, prove Moomoo entitlement/liquidity/history or fabricate historical mandates. `source_asof` is documentation observation date, not mandate effective date. Exact benchmark text and broader controlled exposure family remain separate; sharing a family does not establish an identical benchmark or independent diversification.

`classify_discovered_etfs` returns only supplied discovered codes, with selection eligibility and listing verification false until separate evidence establishes them. Unknown names remain unclassified. Ordinary real-estate ETF wrappers such as XLRE may be considered if independently discovered and eligible; individual REITs, ETNs and plain trusts are not ETF substitutes. Inverse/leveraged classification retains issuer daily reset and signed leverage; multi-day fund forecasts must use actual fund prices, not multiplied/reversed benchmark forecasts.

`ResearchProvider.capabilities()` reports native counts null/methodology-unverified, REST numeric quotas unknown, entitlements/live coverage unverified, cumulative response shape unverified and next_time paging unverified. A successful mock demonstrates implementation handling, not current endpoint permissions, freshness, data rights, full calendar coverage, profitable selection or model quality. A separately approved bounded read-only pilot remains required before claiming live support.
