# Synthetic catalyst replay

`replay_cases(envelope)` in `harness/catalyst_replay.py` is a pure standard-library validator. It requires schema_version 1 and origin `synthetic`. It does not read files, stores, providers, calendars or models, infer causation, select thresholds, train, score predictions or authorize trading. Metadata and URLs are caller assertions, not verified provenance or licenses.

The envelope has aware ISO `decision_cutoff` and `review_at`, with review at/after decision, plus an explicit `cases` list (empty allowed). Each case supplies unique `case_id`, nonempty `instrument`, `venue`, `currency`, `event_cluster_id`, split `train|calibration|test`, aware `information_cutoff`, `outcome_start`, `outcome_end` and explicit `news` list. Information cutoff is at/before decision and strictly before outcome start; start may equal end. A malformed envelope, case identity, interval or news record raises ValueError for the entire replay. No records are silently discarded.

Each news record has unique per-case `news_id`, nonempty `source`, `provider`, `provenance_ref`, `event_cluster_id`, `revision_id`, safe HTTP(S) `source_url`, precision `timestamp|date|unknown`, and annotation `plausible_catalyst|context_correlation|contradictory|unknown`. URLs reject credentials, controls, whitespace, backslashes and malformed/out-of-range ports. Four fields must be present as aware ISO instants or explicit null: `published_at`, `provider_available_at`, `first_observed_at`, `ingested_at`. Date precision does not permit date-only strings in instant fields; use explicit null where an instant is unknown and keep authored date information in optional evidence fields. Each correction is a separate news revision with its own ID/times; no automatic latest selection or inherited availability.

News is prospective only with timestamp precision and complete ordered publication <= provider availability <= first observation <= ingestion <= case cutoff. Exact equality is valid, including timezone-offset representations of the same instant. Missing instants, date/unknown precision, reversed chronology and after-cutoff/review instants generate explicit reason codes. Complete ordered timestamp evidence after case cutoff but known by review is `explanation_only`; evidence after review or with missing/ambiguous/contradictory required timing is `unavailable`. Annotation direction is separate: a timestamp-eligible `contradictory` annotation remains eligible. No exchange auction/session inference is made from cutoff equality.

Each output case retains its original case object in `case`, including its original news list and optional metrics/result references. Independently evaluated news rows retain the entire original news object in `evidence`, including optional news references. These are deep copies preserving original strings, not substitutions or recomputed values. Arbitrary optional envelope fields are not echoed: output envelope metadata is schema_version, origin, decision_cutoff and review_at. Caller metrics/reference values are never used to select input eligibility.

Case `prospective_eligible` represents validated case information timing, not an aggregate news signal. All structurally accepted cases have true eligibility and empty case reason_codes; an empty-news control remains valid. Per-news eligibility remains separate. Case `outcome_status` is available only when outcome_end <= review_at, otherwise pending; outcome_end is the synthetic label-availability contract, not inferred actual reporting delay. Pending outcomes do not change case/news eligibility or generate scores.

Fold diagnostics union each case primary cluster with every news cluster, including future/unknown/excluded evidence, using iterative path compression. A component spanning splits produces `cluster_crosses_splits`. All earlier-split information cutoffs must precede every later-split cutoff; absent splits are valid. Each earlier outcome_end is compared against the earliest later cutoff: equality is available, later produces `outcome_unavailable_at_fitting_cutoff`; if outcome_start <= that cutoff < outcome_end it also produces `outcome_overlaps_fitting_cutoff`. Violations are reported without fold repair. Case/news temporal eligibility remains unchanged by fold validity. There is no predictive score, including for invalid folds.

Summary denominators are explicit case/news counts, with eligible/excluded news, explanation-only/unavailable, empty-news controls and pending outcomes. `unique_cluster_id_count` counts distinct authored IDs; `connected_component_count` counts transitive event components. Multiple articles/revisions may increase news count without increasing component count. Unknown/abstained annotations and ordinary/no-news controls are retained, not removed from denominators.

Run the accepted focused regression command from repository root:

```sh
python3 -m pytest -q tests/test_catalyst_replay.py tests/test_session_metrics.py tests/test_evidence_store.py tests/test_forecast_review.py
```

Synthetic passes do not establish actual exchange calendars, provider availability, data rights, market coverage, causal attribution, feasible fills or investment/model value. Local provider ingestion and any publication remain separate authorized work.
